Patch Info

1. Patch Original
  • Patch Original merupakan Patch Bahasa Indonesia tanpa tambahan patch lainnya.

Preview:

2. Patch Original (Custom Font)
  • Patch Original (Custom Font) merupakan Patch Bahasa Indonesia dengan tambahan patch custom font. Penambahan patch ini dikarenakan ada beberapa user yang terkendala 'force close' atau 'crash' tanpa alasan saat menjalankan game dan memasuki lobby.

Preview:

3. Patch Beta
  • Patch Beta merupakan Patch Bahasa Indonesia yang ditambahkan untuk pengguna (Beta) Fanmade Patch User. Pada patch ini, pengguna Beta dapat melakukan test string, patch, dan lain-lain untuk mencoba preview update string yang akan datang. Isi dari patch Beta adalah gabungan dari Original dan Original (Custom Font).
  • (Patch ini tidak dapat digunakan secara publik)
Cara Menggunakan
  • - Buka Updater Launcher Bahasa Indonesia Fix.
  • - Klik dropdown pada menu 'Pilih Patch' lalu klik salah satu patch yang akan digunakan.
  • - Tunggu hingga Version berubah lalu klik 'Check Update'.
  • - Setelah patch yang dipilih berhasil dipasang, versi 'Installed' akan berubah sesuai dengan patch yang dipilih.
